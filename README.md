# manufacturing-quality-analysis
# 制造业产品品质EDA分析项目
数据集来源：Kaggle Textile Engineering Production Dataset
工具：Python Pandas Numpy Matplotlib

## 项目背景
模拟工厂质检业务，分析生产环境、设备状态和产品缺陷之间关系，挖掘品质问题，给出生产优化建议。

## 分析步骤
1、数据读取与清洗：去重，处理缺失值
2、统计整体不良率，按设备转速、环境湿度、设备维护状态做多维度聚合统计
3、可视化：绘制不良率柱状图、趋势图，对比不同条件缺陷水平
4、输出业务结论，模拟给生产工艺提供参考

## 核心发现
1、整体不良率3.89%；
2、高转速设备缺陷率更高；
3、车间湿度上升，产品缺陷数量随之增加；
4、到达维护周期未保养的机器平均缺陷显著升高。

## 优化建议
1、按时执行设备维护保养；
2、管控车间环境湿度；
3、重点监控高转速机器，增加巡检频次。
